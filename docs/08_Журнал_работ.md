# 8. Журнал работ (шаблон для бригадира)

Журнал ведёт бригадир. Для каждого этапа указывается сложность (вес) в баллах и
срок выполнения. Этапы выбраны в соответствии с типовыми заданиями
методических указаний. Вес работы распределяется между участниками бригады по
степени участия.
