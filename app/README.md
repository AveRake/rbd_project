# Демонстрационное веб-приложение CampusRent

Простейший интерфейс к БД (подмножество системы), реализованный на PHP + PDO.
Позволяет просматривать и редактировать таблицы, а также открывать отчётные
формы — то есть демонстрировать функции всех ролей системы.

## Требования

- PHP 8.0+ с расширением `pdo_mysql`;
- доступ к любому узлу РБД (ЦО или филиалу).

## Запуск

```bash
cd app
DB_HOST=127.0.0.1 DB_PORT=3306 DB_USER=root DB_PASS=password \
  php -S 0.0.0.0:8080
```

Открыть в браузере: <http://localhost:8080/>

Чтобы подключиться к другому узлу РБД, достаточно изменить `DB_HOST`/`DB_PORT`:

| Узел | Порт |
|---|---|
| Центральный офис (master) | 3306 |
| Филиал СПб (slave) | 3307 |
| Филиал Казань (slave2) | 3309 |
| Узел консолидации | 3308 |

## Состав файлов

| Файл | Назначение |
|---|---|
| `config.php` | подключение к БД, список таблиц и групп, вспомогательные функции |
| `index.php` | главное меню: отчёты и переходы к таблицам |
| `table.php` | просмотр и редактирование любой таблицы (добавление/удаление) |
| `reports.php` | отчётные формы |

Приложение работает с теми же ограничениями целостности, что и БД: попытка
нарушить правило (например, выдать занятую технику) завершится ошибкой
триггера, которая будет показана в интерфейсе.
