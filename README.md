# CampusRent — распределённая база данных сервиса аренды техники

Учебный проект по дисциплине «Распределённые базы данных и сетевые
вычисления», МИЭМ НИУ ВШЭ, магистратура.

## Предметная область

Компания **CampusRent** сдаёт в аренду учебную, лабораторную и
демонстрационную технику высшим учебным заведениям: проекторы, ноутбуки,
VR-оборудование, измерительные приборы, аудио- и видеоаппаратуру.

Компания имеет центральный офис и сеть филиалов. Филиал обслуживает вузы
своего региона, хранит закреплённую за ним часть парка техники, принимает
заявки, выдаёт оборудование и ведёт учёт его обслуживания. Центральный офис
ведёт единую номенклатуру и тарифы, реестр вузов и сводную отчётность.

Географически распределённые филиалы, централизованная номенклатура и
необходимость сводной отчётности делают распределённую базу данных
обоснованным решением.

## Запуск

```bash
cd replication
bash setup.sh
```

Стенд из четырёх узлов MySQL 8.0 поднимается в Docker, схема и данные
загружаются автоматически, репликация настраивается скриптом. Порядок
проверки репликации, работы с базой и запуска веб-приложения описан в
[ЗАПУСК.md](ЗАПУСК.md).

## Методы поддержки распределённости

| Метод | Где применён |
|---|---|
| Горизонтальная фрагментация | экземпляры техники — по филиалам |
| Репликация с основной копией | справочники НСИ: номенклатура, тарифы, сотрудники |
| Репликация без основной копии | клиенты: вузы, подразделения, представители |
| Репликация с консолидацией | техника, заявки, договоры, платежи, обслуживание |
| Рабочий поток | согласование заявки между филиалом и центральным офисом |
| Распределённые запросы | поиск свободной техники по всем филиалам |
| Распределённые транзакции | бронирование и перенос техники между филиалами |

## Результаты

- схема базы данных: 22 таблицы, 10 представлений, 18 триггеров;
- тестовый набор: 775 экземпляров техники, 263 заявки, 114 договоров,
  471 выдача, 260 записей обслуживания;
- 18 отчётных запросов выполняются без ошибок — `results/query_results.md`;
- ограничения целостности подтверждены контрольными примерами —
  `results/integrity_tests.md`;
- репликация проверена на стенде — `results/replication_log.md`.

## Технологии

MySQL 8.0, Docker и Docker Compose, PHP 8 с расширением PDO MySQL,
Python 3 для генераторов данных и схем.
