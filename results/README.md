# Результаты прогонов проекта

Каталог содержит результаты фактического выполнения проекта на сервере MySQL
(скрипты выполнены и проверены; см. `tools/run_local_demo.sh`).

| Файл | Содержание |
|---|---|
| `query_results.txt` | полный вывод всех 18 отчётных запросов (`sql/08_queries.sql`) |
| `query_results.md` | сводка ключевых результатов; **генерируется** `tools/gen_query_results.py`, вручную не редактируется |
| `integrity_tests.txt` | протокол проверки ограничений целостности (11 контрольных примеров) |
| `integrity_tests.md` | сводка протокола с ожидаемыми и фактическими результатами |
| `replication_log.txt` / `.md` | протокол проверки репликации: РОК, РБОК, РКД и состояние всех шести каналов |
| `distributed_booking_log.txt` / `.md` | протокол распределённой транзакции РТ-1 (межфилиальное бронирование, 2PC через XA) |
| `graphs/` | графики к итоговому отчёту |
