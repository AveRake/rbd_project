# Графики для итогового отчёта

Каталог предназначен для диаграмм и графиков итогового отчёта. Данные для их
построения уже подготовлены — см. `../query_results.txt` и `../query_results.md`.

Планируемые графики (следующий этап работы):

1. загрузка парка техники по филиалам (столбчатая диаграмма);
2. структура парка по категориям (круговая диаграмма);
3. ТОП-10 моделей по числу выдач (горизонтальная столбчатая);
4. поступления платежей по филиалам (столбчатая);
5. динамика поступлений по месяцам (линейный график);
6. заявки по статусам (круговая);
7. затраты на ремонт по видам работ (столбчатая);
8. средний срок аренды по категориям (горизонтальная столбчатая);
9. наличие техники по филиалам (карта/диаграмма распределения).

Требования к оформлению графиков и слайдов — в документе
«Общие требования к оформлению» (чёрный шрифт на белом фоне, размер не менее 18 пт).
