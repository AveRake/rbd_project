**Примечание по кодировке.** При ручных командах `docker exec ... mysql`
обязателен параметр `--default-character-set=utf8mb4`: в образе контейнера
локаль `C`, и без него клиент переключается на `latin1` — русский текст
искажается, а вставка в поле `VARCHAR(12)` падает с ошибкой
`ERROR 1406: Data too long for column 'EQ_STATUS'`. В конфигурациях стенда
параметр прописан в секции `[client]`, он действует после пересоздания
контейнеров.

Для полноты протокола выполните и приложите вывод:

```bash
docker exec -it mysql-slave  mysql -uroot -ppassword --default-character-set=utf8mb4 -e "SHOW SLAVE STATUS\G" | grep -E "Running|Master_Host"
docker exec -it mysql-consol mysql -uroot -ppassword --default-character-set=utf8mb4 -e "SHOW SLAVE STATUS\G" | grep -E "Running|Channel_Name"
```

Проверка SQL без репликации (схема, данные, запросы, ограничения целостности)
выполнена отдельно — см. `query_results.txt`, `query_results.md`,
`integrity_tests.txt`, `integrity_tests.md`.
